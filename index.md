# Rclone Personal

Configuración de uso personal de rclone para acceder a Google Drive desde Zorin Linux y editar documentos con LibreOffice usando nombres de archivo legibles.

El acceso a Google Drive se realiza mediante autorización OAuth de Google. Las credenciales se guardan en el equipo del propietario. Esta página no solicita credenciales ni proporciona acceso a los archivos de Drive.
